# Deployment & CD Pipeline Setup

Follow the instructions on this [document](https://docs.google.com/document/d/1si3shvRRnsWxLJ3iiLUUQ75mAueIlO3ll_oPZRH4svc/edit?usp=sharing) to get your instance up and running.

Completing these steps also generates a GitHub Actions workflow in your repository that auto-deploys on changes to `main` — this workflow is the deploy stage of the CI/CD pipeline the rest of P3 builds on, so don't remove or replace it later.
